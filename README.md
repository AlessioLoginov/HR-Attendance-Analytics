# HR Attendance Analytics (FEML)


Проект по машинному обучению: прогнозирование риска отсутствия сотрудников на основе исторических данных посещаемости.

---

## 1) Постановка задачи

Цель — построить модель, оценивающую вероятность наличия хотя бы одного дня отсутствия у сотрудника в будущем окне 3 месяца.

Тип задачи:
- бинарная классификация
- риск-скоринг (ранжирование сотрудников по вероятности события)

Модель:
- не прогнозирует конкретные даты,
- не прогнозирует причины отсутствия,
- используется для ранжирования риска.

---

## 2) Данные

Используются два датасета:

### employees
Статические характеристики сотрудников  
- 2 888 сотрудников  
- 18 признаков  

### attendance
История посещаемости  
- 1 265 452 записи  
- период: январь 2023 — декабрь 2024  
- дневной статус: присутствие / отсутствие / опоздание  

Около 10% сотрудников не имеют истории посещаемости.

---

## 3) Временная логика

Для исключения утечки информации используется строгое временное разделение:

- признаки формируются по историческому окну до 30.09.2024  
- таргет рассчитывается по периоду 01.10.2024 — 31.12.2024  

**Таргет:** наличие хотя бы одного дня отсутствия в будущем окне.

---

## 4) Feature Engineering

Логи посещаемости агрегируются на уровень сотрудника.

Сформированы признаки:
- доля отсутствий,
- частота опозданий,
- распределение по дням недели,
- поведенческие агрегаты,
- показатели регулярности.

Итоговый датасет:
- 27 признаков
- 2 496 сотрудников после согласования с таргетом

---

## 5) Метрики

Используются две метрики:

### ROC-AUC
Ключевая метрика риск-скоринга.  
Оценивает способность модели корректно ранжировать объекты.

### PR-AUC (Average Precision)
Дополнительная метрика для анализа качества при дисбалансе классов.  
Используется для дополнительной интерпретации модели в рамках данной постановки.

---

## 6) Используемые модели

- Logistic Regression (baseline)
- Decision Tree
- Random Forest
- XGBoost (baseline)
- XGBoost (tuned)
- Ensemble: Random Forest + XGBoost tuned (soft voting)
- Neural Network (MLP)

---

## 7) Результаты (test)

Лучшая модель — ансамбль Random Forest + XGBoost tuned.

---

## 8) Практическое применение

Модель может использоваться для:

- ранжирования сотрудников по риску отсутствия,
- формирования списков повышенного внимания,
- перехода к проактивному управлению персоналом.

Модель не предназначена для задач найма, так как ключевые признаки формируются из поведенческой истории сотрудника.

---

## 9) Возможные направления развития

- прогноз количества дней отсутствия (регрессия),
- временные признаки (rolling features),
- интерпретация модели (feature importance, SHAP),
- интеграция в HR-процессы с оценкой бизнес-эффекта.


---

## 🧩 Краткие выводы по глубокому обучению

- Модель глубокого обучения не продемонстрировала преимуществ по сравнению с классическими алгоритмами и ансамблями.
- Основной причиной является специфика задачи: признаки представляют собой агрегированные исторические показатели с относительно небольшой размерностью.
- В условиях сильного дисбаланса классов и табличной структуры данных ансамблевые методы деревьев решений (Random Forest, XGBoost) оказываются более устойчивыми и эффективными.
- Проведенный эксперимент подтверждает, что применение глубокого обучения должно быть обосновано структурой данных и задачей, а не использоваться универсально.

Таким образом, результаты deep learning моделей усиливают основной вывод работы и дополнительно обосновывают выбор ансамбля Random Forest и XGBoost в качестве финального решения.
